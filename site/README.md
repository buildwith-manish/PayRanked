# PayRanked link page

Static site, no build step. Cloudflare Pages: build command empty, build output directory `site`.

- Hero: `media/intro.mp4` (web copy of public/intro.mp4, 720p, ~190 KB) with poster `media/intro-poster.jpg`.
- Instagram bio link: `https://YOUR-SITE/?src=ig` hides the Instagram button. `?src=fb` hides Facebook.
- Newsletter: set `NEWSLETTER_ACTION` in index.html to show the signup block.
- Facebook: replace `[PASTE_YOUR_FACEBOOK_PAGE_URL]` in index.html.
