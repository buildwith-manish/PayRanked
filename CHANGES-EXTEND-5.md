# EXTEND-5: regenerate timing, VO cues, music for the 8:28.5 cut

## Why
After EXTEND-1 through EXTEND-4, the timeline, VO cue sheet, and music bed were stale. The total runtime moved from 5:02.5 to 8:28.5 (+206 s), and Shot 5.5 (110 s) is a brand-new section that did not exist in any of those files. EXTEND-5 regenerates them so they match the new cut exactly.

## What changed
- `scripts/timing-entry.ts` — added `shot55` to the `shots` dict (`start: s(START.shot55), dur: SHOT_SECONDS.shot55}`) and to the beats dict (`shot55: secs(T55)`). Imports `T as T55` from `../src/shots/Shot55`.
- `scripts/timing.json` — regenerated by `npm run timing`. Now contains the `shot55` section with `start: 375.5, dur: 110`, plus all 6 beats (hook, profile1, profile2, profile3, formula, tease). Total: 508.50 s (8:28.5).
- `scripts/vo_cues.py` — added `'shot55': 'Practical takeaways'` to the section names dict, and added a `beats('Practical takeaways beats', S['shot55']['start'], TM['shot55'])` call so the cue sheet includes the 6 shot-55 beats.
- `review/VO-CUES.md` — regenerated by `npm run vo-cues`. Now lists all 7 sections (Cold open, Intro, Method, Countdown, Reality check, Practical takeaways, Outro) with the correct start/end times, plus a "Practical takeaways beats" section with all 6 beats.
- `public/music.mp3` — regenerated by `npm run music`. The music bed is rebuilt against the new timeline (508.5 s, 8:28.5). Same key (D minor), same tempo (96 BPM), but the bed is now long enough to cover the new Shot 5.5 section. Size went from 4.8 MB to 8.2 MB (proportional to the +206 s of runtime).
- `src/fontshare/load-fonts.ts` — replaced the static `import "./fonts.css"` with a runtime `staticFile()`-based `@font-face` injection. The old approach used absolute URLs (`/fonts/...`) in `fonts.css` that webpack's css-loader tried to resolve at build time and failed on (`Error: Can't resolve '/fonts/fontshare/satoshi/Satoshi-Variable.woff2'`). The new approach builds the CSS string with `staticFile()` calls and injects it via a `<style>` tag at module load, which Remotion's bundler handles correctly. This was the only thing blocking `npx remotion compositions` from listing the new `Shot55-Practical` composition.
