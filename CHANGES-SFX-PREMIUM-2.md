# SFX premium upgrade pass 2: real foley layering + DSP upgrades + DC fix

## What changed

### 1. Real foley layering (the biggest jump)
Premium sound design is mostly real foley mixed with synthesised sub and tails. This commit adds a complete pipeline:

- `foley/raw/` — 6 real recorded foley samples (CC0 coin drop from OpenGameArt; archive.org William Dyer library: crash, door slam, glasses hitting, metal scratching, punches)
- `scripts/prepare_foley.py` — slices multi-hit files at transient points, normalises to -1 dBFS, resamples to 48 kHz mono, writes to `foley/processed/` (25 slices from 6 raw files)
- `foley/layer_map.json` — maps 13 SFX names to foley samples with gain + offset:
  - `coin_0..3` → real coin drop (CC0, gain 0.18-0.22)
  - `hit_big` → real crash (gain 0.12, subtle layer under synth sub)
  - `hit_med`, `hit_small` → real punches (gain 0.15-0.18)
  - `stamp` → real door slam (gain 0.15)
  - `lock` → real metal scratching (gain 0.12)
  - `ding`, `ding_hi`, `bell_ring` → real glasses clinking (gain 0.08-0.10, very subtle)
  - `pin_land` → real punch (gain 0.15)
- `scripts/make_sfx.py` — `get_foley()` function loads and caches foley samples; `finish()` mixes foley BEFORE normalisation so it becomes part of the sound, not a layer on top. The LOCKED RMS check keeps the overall loudness within tolerance.

### 2. DC offset fix (tick_1 bug)
The old code only high-passed at 15 Hz (67ms time constant), which is longer than tick files (60ms). For very short files the Butterworth filter can't remove DC — its impulse response is longer than the file, so the zero-phase `sosfiltfilt` reintroduces edge artifacts.

**Fix:** subtract the mean BEFORE the high-pass (removes the bulk of DC for all files), and skip the Butterworth entirely for files shorter than 100ms (rely on mean subtraction alone).

Verified: tick_1.wav mean went from +0.0176 (audible pop) to -0.000252 (clean).

### 3. True-peak limiter
`true_peak_limit()` in `finish()`: 4x oversamples the signal to detect inter-sample peaks, then limits to -1 dBFS. Prevents clipping when the audio is played back through a DAC that does sinc reconstruction (which can produce peaks between samples that exceed the digital peak).

### 4. Transient shaper
`transient_shaper()` in `finish()`: for hits and impacts (hit_big, hit_med, hit_small, stamp, lock, pin_land, pop, click), boosts the attack by 1.25x and reduces the sustain by 0.88x in the 1.25-5 kHz band. Makes the "snap" of each impact sharper without changing the overall level.

## How to add more foley
1. Drop a raw WAV in `foley/raw/`
2. Run `python3 scripts/prepare_foley.py` (slices it into individual hits)
3. Add an entry to `foley/layer_map.json`: `"sfx_name": {"file": "processed_name_00.wav", "gain": 0.15, "offset": 0.0}`
4. Run `python3 scripts/make_sfx.py` (regenerates all SFX with the new foley layered in)
